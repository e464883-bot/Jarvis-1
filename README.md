# Jarvis 1 · El atlas del reino

Infografía interactiva de worldbuilding socioeconómico con pestañas, ocho sistemas y laboratorio de conflictos. Los escenarios son ficticios y no constituyen predicciones económicas.

Abrir index.html en el navegador. La ilustración está integrada; el widget requiere conexión a ElevenLabs.
